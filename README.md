# Java Study

---


- 운영 기간: 2026.09.14 ~ 2026.12.22
- 운영 횟수: 총 15주
- 학습 분야: Java
- 진행 방식: 개별 학습 + GitHub 기록 + 주 1회 질의응답
- 학습 기록: 주차별 브랜치에 개념 정리, 예제 코드, 문제 풀이 업로드
- 문제 풀이: 백준, 프로그래머스 등을 활용하여 주차별 학습 내용과 관련된 문제 풀이

---

- Java의 기본 문법과 핵심 개념을 단계적으로 학습한다.
- 직접 코드를 작성하고 문제를 해결하며 프로그래밍 문제 해결 능력을 기른다.
- 매주 학습 내용을 GitHub에 기록하여 꾸준한 학습 습관을 만든다.
- 서로의 코드와 풀이 방법을 공유하며 다양한 문제 해결 방식을 학습한다.
- 정기적인 질의응답을 통해 부족한 개념을 보완한다.

---

1. 매주 정해진 Java 학습 범위를 공부합니다.
2. 학습한 개념을 정리하고 관련 예제 코드를 작성합니다.
3. 해당 주차 학습 내용과 관련된 문제를 최소 2~3문제 풀이합니다.
4. 개념 정리, 예제 코드, 문제 풀이를 해당 주차 브랜치에 업로드합니다.
5. 매주 대면 또는 비대면 모임을 진행합니다.
6. 모임에서는 학습 과정에서 생긴 질문과 어려웠던 부분을 공유합니다.
7. 서로의 문제 풀이 방법과 코드를 비교하며 다양한 해결 방법을 학습합니다.
8. 마지막 주에는 전체 학습 내용을 복습하고 GitHub 기록을 정리합니다.
